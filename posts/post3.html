Arrays & Data Structures

Managing player and dealer cards dynamically

I added two new integer arrays to track the cards for the player and the dealer. I set the size to 10 because you won't have more than 10 cards in a hand in Blackjack. 

int[] pCards = new int[10];
int[] dCards = new int[10];

// Displaying the cards using the array
for (int i = 0; i < pCount; i++) {
  image(suit[pCards[i]], 630 + (i*120), 740, 150, 210);
}

To store multiple items, I created an array with a fixed size (10) and then assigned values to each index as the game goes on. For example, when the player hits, I generate a random number between 0 and 12 and store it in the pCards array. To access them, I use the index of the array inside a loop. In the code above, pCards[i] lets me get the value of a card, so I know which image to draw.

These arrays help my game by letting the hand size change dynamically. Without them, I would need variables like card1, card2, card3, etc., which would make the code really messy and hard to manage. Using arrays makes it easy to calculate the total score of the hand just by looping through all of the items in the array.
