Using loops to efficiently load card images

I implemented a for loop to load all the card images into my arrays. 

String[] ranks = {"Ace", "2", "3", "4", "5", "6", "7", "8", "9", "10", "Jack", "Queen", "King"};

for (int i = 0; i < 13; i++) {
  spades[i]   = loadImage("Type = " + ranks[i] + " (Spades).png");
  hearts[i]   = loadImage("Type = " + ranks[i] + " (Hearts).png");
  clubs[i]    = loadImage("Type = " + ranks[i] + " (Clubs).png");
  diamonds[i] = loadImage("Type = " + ranks[i] + " (Diamonds).png");
}

I used this code inside the setup() function. First, the 4 PImage arrays are loaded (spades, hearts, clubs, diamonds) with the correct image files. I implemented it this way because there are 52 cards in a deck, and writing a separate loadImage line for every single card would be inefficient and take up too much space. By using a loop that runs 13 times (0 to 12), I can load the card for all four suits at the same time, keeping the code clean.

The biggest challenge I had was that my file names had specific names ("Ace", "Jack", "Queen", etc.). I was going to use the loop number for the file name (like 1.png, 2.png, etc.), but that wouldn't work for the face cards and different card types. To fix this, I created an array called ranks that lists the names of the cards in the correct order.
