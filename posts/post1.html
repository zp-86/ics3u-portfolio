Variables & Data Tracking

Reflection on game state management

The game I have chosen to make is a blackjack game. I will need a lot of different variables to track things like the game state, player info, and overall statistics. The first set of variables I will add is for the assets. I will need to use a loop to add all 52 different cards in a deck to a PImage array. I'll make each card's file name a number so that I can increment the loop by one to get to the next card image. Arrays are the best choice because with 52 cards, I would need to create 52 different variables for each card, which is inefficient. I'll have different arrays for each card type, so the user can select the one they want in the customization menu. To switch between the card types (hearts, diamonds, etc), there will be a variable called 'activePair' that will match the user's selection. Then, when displaying the cards in my code, I can use if statements to check 'activePair' and display the card type the user selected (index 0-3).
