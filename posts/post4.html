Selection Structure

Determining winners with conditional logic

I used if and if-else statements to find the winner of each round. 

if (pTotal <= 21 && (dTotal > 21 || pTotal > dTotal)) { // Player win
  coins += currentBet;
  coinsEarned += currentBet;
} else if (pTotal > 21 || (dTotal <= 21 && dTotal > pTotal)) { // Dealer Win
  coins -= currentBet;
  gamesLost++;
}

I used this inside the resolveRound() function. The code checks the final scores of the player and the dealer, and it finds out who won the round. I implemented it this way because there are multiple conditions to win a round in Blackjack. The player wins if they have 21 or less AND the dealer busts (over 21) OR if the player's score is higher than the dealer's. If I didn't use AND and OR in my code, I would have had to write a bunch of if statements, which would be messy.

The challenge I had was when the dealer and player tie, and making sure the logic covered every possibility. Originally, I just checked if the player's total was greater than the dealer's total, but that didn't check if the player busted. If the player had 22, they should lose immediately. I fixed this by adding a check to see if the player's total is less than or equal to 21. I also realized I didn't need a separate code block for a tie, if the player did not bust, but also does not have more or less than the dealer (None of the if's are true), nothing happens to the money, which is how a tie works.
