Use of Custom Functions & Error Checking/Restrictions

Writing reusable code and preventing errors

The code I wrote has lots of custom functions and handles errors. An example function is the calculateTotal function. 

int calculateTotal(int[] hand, int count) {
  int total = 0;
  int aces = 0;
  for (int i = 0; i < count; i++) {
    int val = hand[i] + 1;
    if (val > 10) val = 10;
    if (val == 1) aces++;
    total += val;
  }
  for (int i = 0; i < aces; i++) {
    if (total + 10 <= 21) total += 10;
  }
  return total;
}

The function loops through the hand array and calculates the score. It supports the game because I need to check the score for the player and the dealer, in a bunch of different places (like in updateDealer and resolveRound). If I didn't use a function, I would have to write the logic every time, making the code really long and messy. It also helps because I can code in the exact rules of blackjack (like how all face cards are worth ten and how aces are worth 1 or 11) and just call one easy function, making my code more optimized.

Error Checking & Restrictions

For error checking and restrictions, inside the mousePressed function, the code checks if (currentBet + 10 <= coins). When the player clicks on the chip, the code adds 10 to the bet amount, but if the user does not have 10 more coins to add (the bet was at 100, and they have 100 coins), they should not be able to increase their bet, which is what the code checks.

The code also makes sure there are no errors when loading the save file using if (data != null && data.length >= 3). If the save file does not exist, the code won't try to load it, avoiding an out of bounds error.
